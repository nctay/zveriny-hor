# Звериный хор

Навык Алисы проигрывает 54 короткие записи животных. «Собака», «собачка» и «пёсик» включают лай собаки. «Щенок» и «щеночек» включают запись щенка. Словарь понимает также реплики вроде «А как мяукает кошечка?», «Включи звук морской свинки» и «Как говорит детёныш лошади?».

## Подключить к своей Станции

Для настройки нужны один аккаунт Яндекса для навыка, Облака и Станции, а также активный платёжный аккаунт в Yandex Cloud. [Подготовка Yandex Cloud](https://yandex.cloud/ru/docs/tutorials/serverless/alice-skill/console#before-you-begin)

1. В [консоли Яндекс Диалогов](https://dialogs.yandex.ru/developer/) выбери **Создать диалог → Навык в Алисе**. Назови его **Звериный хор**, выбери тип доступа **Приватный** и сохрани черновик. Backend можно добавить после загрузки аудио. Скопируй идентификатор навыка внизу вкладки **Общие сведения**. [Создание навыка](https://yandex.ru/dev/dialogs/alice/doc/ru/skill-create-console)
2. Получи OAuth-токен по ссылке в разделе **Авторизоваться** документации Яндекс Диалогов. Открой терминал в папке проекта и выполни команду, подставив идентификатор. Вставь токен в скрытый запрос терминала. [Получить токен Яндекс Диалогов](https://oauth.yandex.ru/authorize?response_type=token&client_id=c473ca268cd749d3a8371351a8f2bcbd)

   ```bash
   python3 prepare.py ИДЕНТИФИКАТОР_НАВЫКА
   ```

   Скрипт загрузит 54 записи, дождётся обработки и соберёт `zveriny-hor.zip`. Если загрузка прервётся, запусти команду повторно с тем же идентификатором. Скрипт повторно использует файлы с совпадающим содержимым. [API звуков Яндекс Диалогов](https://yandex.ru/dev/dialogs/alice/doc/ru/resource-sounds-upload)
3. В [Yandex Cloud](https://console.yandex.cloud/) создай **Cloud Functions → Функция** с именем `zveriny-hor`. Создай версию с **Python 3.14**, источником кода **ZIP-архив** и архивом из предыдущего шага. Точка входа `skill.handler`, таймаут 2 секунды, память 128 МБ. [Настройка функции](https://yandex.cloud/ru/docs/tutorials/serverless/alice-skill/console)
4. В настройках навыка выбери **Backend → Функция в Яндекс Облаке → zveriny-hor**. Оставь опцию **Нужно устройство с экраном** выключенной. Для команды «Ещё раз» включи **Использовать хранилище данных в навыке**. Последняя запись запоминается до выхода из навыка. [Настройки навыка](https://yandex.ru/dev/dialogs/alice/doc/ru/publish-settings) · [Хранение состояния](https://yandex.ru/dev/dialogs/alice/doc/ru/session-persistence)
5. На вкладке **Тестирование** введи «собачка», «щенок» и «морская свинка». Заполни поля приватной публикации. Пример запроса — «Запусти навык Звериный хор». Описание — «Послушай, как звучат 54 животных. Назови животное или спроси, как оно говорит». Выбери категорию **Для детей**, укажи имя разработчика и загрузи [иконку 224 × 224](icon.png). Нажми **Опубликовать**, дождись автомодерации и проверь на Станции с тем же аккаунтом. [Тестирование](https://yandex.ru/dev/dialogs/alice/doc/ru/test) · [Приватная публикация](https://yandex.ru/dev/dialogs/alice/doc/ru/skill-create-console)

## Настроить вопросы без названия навыка

После приватной публикации сначала проверь на Станции команду «Алиса, попроси Звериный хор включить один раз собаку». Должен прозвучать только лай, затем навык завершит диалог. Если выберешь другое активационное имя, подставь его и сюда, и в действия сценариев. [Запуск навыка с командой](https://yandex.ru/dev/dialogs/alice/doc/ru/activation)

1. В **Доме с Алисой** открой **+ → Сценарий** и назови его «Лай собаки».
2. В блоке **Если → Добавить условие → Фраза** введи «как говорит собачка». Добавь через **ИЛИ** ещё две фразы — «как говорит собака» и «как лает собака». В поля с фразами вводи текст без слова «Алиса». [Запуск голосом](https://alice.yandex.ru/support/ru/smart-home/scenarios/voice) · [Несколько условий](https://alice.yandex.ru/support/ru/smart-home/scenarios/few-conditions)
3. В блоке **Тогда → Добавить действие → Устройство** выбери свою Станцию и действие **Ответить на вопрос или выполнить команду**. Введи «Попроси Звериный хор включить один раз собаку». Сохрани и скажи «Алиса, как говорит собачка?». [Произвольное действие на колонке](https://inclusion.yandex.ru/tutorials/smart-home-with-alice-ios-part3)
4. Для щенка сделай отдельный сценарий с фразами «как говорит щенок» и «как лает щеночек». В действии укажи «Попроси Звериный хор включить один раз щенка». Для остальных звуков повтори настройку по этому образцу. [Список записей](audio/SOURCES.md)

Если дома несколько Станций, в шаге 3 можно выбрать **Любое умное устройство**. Тогда команду выполнит колонка, которая услышала голосовую фразу. В меню **Место активации голосом** можно выбрать дом или комнаты с нужными колонками. [Настройка голосовых сценариев](https://alice.yandex.ru/support/ru/smart-home/scenarios/voice) · [Выполнение на колонке, запустившей сценарий](https://inclusion.yandex.ru/tutorials/smart-home-with-alice-ios-part3)

В «Доме с Алисой» варианты фраз добавляются в сценарий заранее. Внутри уже открытого навыка можно говорить свободнее. Например, после «Запусти навык Звериный хор» скажи «А как говорит кошечка?», потом «Щенок», потом «Ещё раз».

### Добавить сценарии через Quasar

Сначала проверь разовый вызов на Станции из предыдущего раздела. Посмотреть все фразы можно локально, без входа и изменений в Доме с Алисой:

```bash
python3 quasar_scenarios.py
python3 quasar_scenarios.py --only dog --only puppy --only cat --only kitten
```

Скрипт сочетает «как говорит» и подходящие глаголы с каждым названием из [словаря фраз](scenario_phrases.txt). Формы в вопросах стоят в именительном падеже. «Как лает пёсик» ведёт к собаке, «как лает щеночек» — к щенку. Яндекс принимает до четырёх голосовых фраз на сценарий, поэтому 319 фраз для 54 звуков распределены по 97 сценариям. Группы одного звука выполняют одинаковую команду.

Для запуска этого скрипта нужен Google Chrome. В Safari можно создавать сценарии в уже открытом аккаунте через [веб-интерфейс Дома с Алисой](https://yandex.ru/iot/). Скрипт открывает отдельный сеанс Chrome со своим входом. В папке проекта подготовь окружение один раз:

```bash
python3 -m venv .venv-quasar
.venv-quasar/bin/python -m pip install playwright
```

Начни с одного сценария:

```bash
.venv-quasar/bin/python quasar_scenarios.py --apply --only rooster
```

В открывшемся окне Chrome войди в нужный Яндекс ID и вернись в Терминал. Нажми Enter, выбери номер Станции, проверь список и введи `да`. После создания скажи «Алиса, как говорит петух?» и «Алиса, как кукарекает петушок?». Обе фразы должны включить запись петуха.

Если обе фразы сработали, тем же способом добавь остальные сценарии:

```bash
.venv-quasar/bin/python quasar_scenarios.py --apply
```

Если голосовая фраза уже выполняет ту же команду на той же Станции, скрипт её пропустит. При конфликте с другой командой скрипт остановится до создания сценариев. Если создание прервётся, повторный запуск сверит список с уже созданными. Quasar — внутренний API Яндекса. Поэтому сначала проверь один сценарий на своей Станции. [Пример формата запросов Quasar в YandexStation](https://github.com/AlexxIT/YandexStation/blob/master/custom_components/yandex_station/core/yandex_quasar.py)

```bash
python3 -m unittest -v
```

Проверки используют тестовые идентификаторы, без обращения к Яндекс Диалогам. Лицензии всех файлов указаны в [источниках](audio/SOURCES.md). Клип гусёнка предназначен для некоммерческого использования.
